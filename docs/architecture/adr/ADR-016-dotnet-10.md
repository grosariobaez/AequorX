# ADR-016 — .NET 10 / ASP.NET Core 10

**Status:** Accepted

## Context

The MVP needs one maintainable backend runtime with strong Azure SQL and observability support.

## Decision

Use .NET 10 LTS, ASP.NET Core 10, and C# for the backend.

## Consequences

The MVP has one backend runtime. Additional runtimes require a new approved ADR.
